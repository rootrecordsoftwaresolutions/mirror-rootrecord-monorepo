Install

  1. Install Root-Core and Root-Perms.
  2. Download from the catalog or let Core pull from manifest.json.
  3. /t redirects register only when Towny is not installed.
  4. Do not install on the Towny host. Official Claims pairs with Towny via RootMC-Official.
  5. Player guide: wiki/claims — first area is free; areas 2–3 are wallet-paid.
