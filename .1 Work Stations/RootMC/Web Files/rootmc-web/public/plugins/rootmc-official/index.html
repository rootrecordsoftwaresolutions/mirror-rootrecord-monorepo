RootMC-Official

Links the official Towny and Claims hosts for progression (playtime, mcMMO, votes, perms network). Gold wallets stay per-host. Not for random third-party servers.

Install (official hosts only)

  1. Install on both Claims and Towny with matching peer config.
  2. Requires Core + shared MySQL peer settings in plugins/RootMC/rootmc-official.yml.
  3. Leave enabled: false until peer + MySQL are ready, then enable on both.
  4. Commands: /rootmcofficial status|sync (ops).

What it is not

Does not replace RootMC, merge economies, or act as a public multi-realm bridge. Single-host operators should skip this jar.
