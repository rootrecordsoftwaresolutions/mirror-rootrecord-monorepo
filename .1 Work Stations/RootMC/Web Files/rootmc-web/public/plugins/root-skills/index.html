Install

  1. Drop root-skills-*.jar into plugins/ (remove older same-plugin jars).
  2. Ensure plugins/RootMC/database.yml points at your suite MySQL (same file Economy / Times use).
  3. Leave mysql.host blank in plugins/Root-Skills/config.yml — localhost defaults inherit the shared file.
  4. Restart Paper. Confirm console: MySQL pool ready (not memory-only).
  5. mcMMO cutover: dry-run then apply with /rootskills migrate, then remove mcMMO after verify.

PROP-01 XP curve

Defaults: multiplier 1.6, exponent 2.35, base 500. Approx xpToNext: L1≈500 · L25≈3.6k · L50≈16k · L100≈81k. Legacy flat triples auto-migrate on enable.
