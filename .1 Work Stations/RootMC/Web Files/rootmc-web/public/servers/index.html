Operators

Server setup

Public suite jars live on the plugins catalog. Official RootMC runs a Towny host and a Claims host linked by RootMC-Official.

Shared spine

  1. Install Root-Core — set server-name + product-key in plugins/RootMC/root-core.yml.
  2. Add Root-Times and Root-Perms (MySQL via database.yml).
  3. Continue with Essentials / Play / Ops / Territories / RootMC from the catalog. Auto-updates use manifest.json.

Host packs

  • Towny host — Vault + Towny + suite (skip Root-Claims). Needs Vault for Towny.
  • Claims host — Root-Claims + suite (no Vault/LuckPerms required).
  • Official pair only — RootMC-Official on both hosts; each peer: points at the other MySQL. Syncs playtime / mcMMO / votes / network perms — not Gold or inventories. Auto-updates via Root-Core + manifest.json (no public guide page).
