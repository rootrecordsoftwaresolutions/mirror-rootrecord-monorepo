## Player-facing changes

### New commands & features
- **`/back`** — return to last death/teleport location (Root-Essentials)
- **`/rtp`** — random teleport during **24h new-player grace** only
- **24h grace** — keep inventory on death, skip PvP death tax, wilderness build warnings (value-scaled)
- **`/rootmc claim-return`** — one-time **1000 G** for returning players (before fresh map); requires **`/link`**

### Economy & shops
- **Loan cap** — borrow limit = `min(rank limit, wallet balance)` (`min_both`)
- **`/buy` fix** — balance rounding edge case resolved
- **Embassy plots** — default **100 G** (paid onboarding; staff policy: no free town-start grants)

### Returning players
- Staff moved builds from the old map where possible
- Claim **1000 G** once: **`/link`** → **`/rootmc claim-return`**
- Eligible if: joined before 2026-07-01, OR Towny resident record

### Towny / map context
- Fresh map launch — **reclaim plots** on new terrain; town names and banks unchanged
- Town upkeep **0 G**, daily taxes **off** — towns are not deleted by upkeep
