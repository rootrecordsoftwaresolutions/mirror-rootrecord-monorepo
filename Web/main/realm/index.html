How verification works

  1. Join the server and run /rootstat link to get a one-time code.
  2. Open rootrecord.info/realm/verify, sign in, and enter the code.
  3. RootStat syncs your link to the server MySQL cache and your public stats page.
  4. Run /rootstat anytime for your stats URL — skills update on the next sync.

McMMO on the web

RootStat reads skill levels from your existing McMMO MySQL tables (mcmmo_users + mcmmo_skills) and pushes snapshots to RootRecord on each sync. No extra McMMO plugin required — just shared MySQL credentials in rootstat.yml.
