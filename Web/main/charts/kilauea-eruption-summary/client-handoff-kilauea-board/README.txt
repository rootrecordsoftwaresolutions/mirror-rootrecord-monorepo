Kīlauea eruption summary — static client pack

Files:
  index.html       — single-page board + modal UI
  episodes-data.js — episode dataset (loaded before the inline script)

Use:
  • Keep both files in this folder together.
  • Open index.html in a browser, or serve this folder with any static file server.
  • Google Fonts load from the network (Inter, Oswald); offline, system fonts are used.

Data sourcing is documented on-page (USGS HVO Kīlauea eruption information).
