Products / BlockNotes

BlockNotes.

Native Android companion for Minecraft players — offline-first notes, coordinates, worlds, timelines, reference lookups, and build plans. Not affiliated with Mojang or Microsoft.

Coming soon

Android on Google Play

BlockNotes (com.rootrecord.blocknotes) is a native Kotlin app in active development. Sign up for a RootRecord account to hear about beta builds and the Play Store launch.

Create an account Join Discord
Features

Built for survival and creative play.

●

Notes & notebooks

Markdown notes organized by world and topic. Search across everything offline.

●

Coordinates

Save and convert overworld, nether, and end coordinates with quick-copy formats.

●

Reference library

Blocks, items, mobs, potions, enchantments, and trades bundled for offline lookup.

●

Build plans

Track materials and steps for large builds without alt-tabbing to wikis.

●

Timeline

Log milestones and session notes per world.

●

RootRecord sign-in

Optional account for sync and member features where enabled.

Platform

Android-first native app (Jetpack Compose). No web or Windows build in the initial release.
