# Root Farms (web)

Idle **plots & rows** game for **Root Units**. Vite + React.

- **Concept / API sync:** [`Web/main/root-farms/README.md`](../../main/root-farms/README.md)
- **Desktop web (Pages):** this project — left nav + plot/row grids
- **Mobile shell:** [`Web/apps/root-farms-mobile-web`](../root-farms-mobile-web) → [`Mobile/root-farms-app`](../../../Mobile/root-farms-app)

## Commands

```powershell
pnpm install
pnpm run dev
pnpm run build
pnpm run pages:deploy
```

`VITE_ROOTRECORD_API_ORIGIN` — optional; defaults to `rootrecord-api-account` Workers dev URL.
