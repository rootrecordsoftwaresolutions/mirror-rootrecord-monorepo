Put your custom AccuWeather-style icons here.

Filenames must be the AccuWeather WeatherIcon code:
- 1.svg
- 2.svg
...
- 44.svg

The app will try to load:
  /weather-icons/accu/<code>.svg

If the file is missing, it automatically falls back to the built-in free icon pack
bundled via `react-icons` (Weather Icons set).
